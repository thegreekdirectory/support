## Before you start

The install experience works best in **Google Chrome** on Android. It also works in Edge and some other Chromium-based browsers, but Chrome is recommended.

## Method 1: The automatic install banner

When you visit [thegreekdirectory.org](https://thegreekdirectory.org) in Chrome on Android, a banner may appear at the **bottom of the screen** that says:

> "Add The Greek Directory to Home screen"

Tap the banner, then tap **Install** in the prompt that appears. Done.

If the banner doesn't appear, use Method 2 below.

## Method 2: The Chrome menu

  <li class="art-step">
    <span class="art-step-num">1</span>
    <div class="art-step-body">
      <strong>Open Chrome and go to <span class="art-code">thegreekdirectory.org</span>.</strong>

  <li class="art-step">

    <div class="art-step-body">

  <li class="art-step">
    <span class="art-step-num">4</span>
    <div class="art-step-body">
      <strong>Tap "Install"</strong> or <strong>"Add"</strong> in the confirmation dialog.
    </div>
  </li>
</ol>

The app installs and the icon appears on your home screen and in your app drawer.

## What to expect after installing

- The app opens **full-screen** with no Chrome browser UI
- A **bottom dock** appears with navigation tabs
- Android may show a brief splash screen on first launch

## Troubleshooting

**"Install app" doesn't appear in the menu** — The option only appears if Chrome determines the site meets PWA criteria. Try reloading the page and waiting a few seconds before opening the menu.

**The app opens in a browser tab instead of full-screen** — Uninstall the shortcut (long-press the icon → Remove/Uninstall), then reinstall using the menu method above.
