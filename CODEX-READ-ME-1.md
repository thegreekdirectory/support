## What is a PWA?

A **Progressive Web App (PWA)** is a website that can be installed on your device's home screen — just like an app from the App Store or Google Play — without actually going through an app store. It uses your browser's built-in install capability.

The Greek Directory is a PWA available at [thegreekdirectory.org](https://thegreekdirectory.org).

## How it's different from using the website in a browser

| Feature | Regular browser | Installed PWA |
|---|---|---|
| Home screen icon | ✗ | ✓ |
| Full-screen (no browser UI) | ✗ | ✓ |
| Bottom navigation dock | ✗ | ✓ |
| Offline access to starred listings | ✗ | ✓ |
| Faster launch time | ✗ | ✓ |
| Background cache updates | ✗ | ✓ |
| App store required | — | ✗ No |

## What you get when you install

- A **home screen icon** that launches TGD in full-screen mode
- A **bottom navigation dock** with tabs for Home, Listings, Map, Starred, and Settings
- **Offline access** to your starred businesses and core pages
- **Automatic updates** applied silently in the background
- A native-feeling experience with smooth transitions and no browser address bar

## What you don't need

- An account or login
- Any payment or subscription
- App Store or Google Play

Simply visit the site in your mobile browser and follow the install steps for [iOS](/article/users/install-ios) or [Android](/article/users/install-android).

## Before you start

You must use **Safari** on iPhone or iPad. The PWA install option is not available in Chrome, Firefox, or other browsers on iOS — this is an Apple restriction, not a TGD limitation.

## Installation steps

<ol class="art-steps">
  <li class="art-step">
    <span class="art-step-num">1</span>
    <div class="art-step-body">
      <strong>Open Safari and go to <span class="art-code">thegreekdirectory.org</span>.</strong>
      Wait for the page to fully load.
    </div>
  </li>
  <li class="art-step">
    <span class="art-step-num">2</span>
    <div class="art-step-body">
      <strong>Tap the Share button.</strong>
      On iPhone, it's the box-with-arrow-up icon (⬆) at the bottom center of the screen. On iPad, it's in the top toolbar.
    </div>
  </li>
  <li class="art-step">
    <span class="art-step-num">3</span>
    <div class="art-step-body">
      <strong>Scroll down in the share sheet and tap "Add to Home Screen."</strong>
      It has a plus-in-a-square icon. If you don't see it immediately, scroll down — it's below the row of app icons.
    </div>
  </li>
  <li class="art-step">
    <span class="art-step-num">4</span>
    <div class="art-step-body">
      <strong>Confirm the name and tap "Add"</strong> in the top-right corner of the screen.
      The name defaults to "Greek Directory" — you can change it if you like.
    </div>
  </li>
</ol>

The app icon now appears on your home screen. Tap it to launch the full-screen experience.

## What to expect after installing

- The app opens **full-screen** with no Safari address bar or tabs
- A **bottom dock** appears with navigation tabs
- On first launch, core pages and your starred listings are cached for offline use

## Troubleshooting

**"Add to Home Screen" is missing from the share sheet** — Make sure you're using Safari, not an in-app browser (like a browser opened from inside another app). Open Safari directly from your home screen.

**The icon looks like a generic bookmark** — This is a display issue that usually resolves after closing and reopening Safari, or restarting your device.

## Before you start

The install experience works best in **Google Chrome** on Android. It also works in Edge and some other Chromium-based browsers, but Chrome is recommended.

## Method 1: The automatic install banner

When you visit [thegreekdirectory.org](https://thegreekdirectory.org) in Chrome on Android, a banner may appear at the **bottom of the screen** that says:

> "Add The Greek Directory to Home screen"

Tap the banner, then tap **Install** in the prompt that appears. Done.

If the banner doesn't appear, use Method 2 below.

## Method 2: The Chrome menu

<ol class="art-steps">
  <li class="art-step">
    <span class="art-step-num">1</span>
    <div class="art-step-body">
      <strong>Open Chrome and go to <span class="art-code">thegreekdirectory.org</span>.</strong>
    </div>
  </li>
  <li class="art-step">
    <span class="art-step-num">2</span>
    <div class="art-step-body">
      <strong>Tap the three-dot menu (⋮)</strong> in the top-right corner of Chrome.
    </div>
  </li>
  <li class="art-step">
    <span class="art-step-num">3</span>
    <div class="art-step-body">
      <strong>Tap "Add to Home screen"</strong> or <strong>"Install app"</strong> — the exact label varies by Android version and Chrome version.
    </div>
  </li>
  <li class="art-step">
    <span class="art-step-num">4</span>
    <div class="art-step-body">
      <strong>Tap "Install"</strong> or <strong>"Add"</strong> in the confirmation dialog.
    </div>
  </li>
</ol>

The app installs and the icon appears on your home screen and in your app drawer.

## What to expect after installing

- The app opens **full-screen** with no Chrome browser UI
- A **bottom dock** appears with navigation tabs
- Android may show a brief splash screen on first launch

## Troubleshooting

**"Install app" doesn't appear in the menu** — The option only appears if Chrome determines the site meets PWA criteria. Try reloading the page and waiting a few seconds before opening the menu.

**The app opens in a browser tab instead of full-screen** — Uninstall the shortcut (long-press the icon → Remove/Uninstall), then reinstall using the menu method above.

## What is the dock?

The **bottom navigation dock** is a native-style tab bar that appears at the bottom of the screen when you use The Greek Directory as an installed PWA app. It replaces the site header navigation and gives you instant one-tap access to the main sections.

The dock is **only visible in the installed app** — it does not appear when browsing the site in a regular browser tab.

## The five default tabs

| Tab | Icon | What it opens |
|---|---|---|
| **Home** | 🏠 | The main directory homepage |
| **Listings** | 🔍 | The full filterable listings directory |
| **Map** | 🗺️ | The full-screen interactive map |
| **Starred** | ★ | Your saved/favorited businesses |
| **Settings** | ⚙️ | App settings and preferences |

The active tab is highlighted in blue. Tapping an already-active tab **reloads the page** (with a brief haptic pulse on supported devices).

## The More menu

If you have more dock items than the five visible slots (after customizing), a **More** button appears as the fifth tab. Tapping it opens an overflow menu with the additional items.

## Long-press to reload

On any active tab, **long-pressing** (holding for ~0.5 seconds) triggers a page reload for that section. This is useful if content feels stale without having to pull down to refresh.

## Safe area handling

On iPhones with a home indicator (Face ID models), the dock automatically respects the safe area so it never overlaps the system home indicator bar.

## Dock on landscape / tablet

On wider screens, the dock stays at the bottom in the same layout. On very wide screens (like iPad in landscape), the dock items spread out proportionally.

## Reordering dock items

Drag any dock item left or right to change its position. The item snaps into its new slot when you release. Changes take effect immediately — the dock at the bottom of the screen updates in real time as you drag.

## Adding items to the dock

Below the current dock layout is a list of **available apps** not currently in the dock. Tap the **+** button next to any item to add it to the dock.

Available items include:
- About
- Submit a Listing
- Business Portal
- Categories
- Any other pages in the directory

The dock supports up to 5 visible tabs. If you add a sixth, it moves to the **More** overflow menu automatically.

## Removing items from the dock

Tap the **−** (minus) button on any dock item in the customization view to remove it. Removed items go back into the available list and can be re-added any time.

## Restoring defaults

Tap **Reset to Default** in the Customize Dock section to restore the original five tabs: Home, Listings, Map, Starred, Settings.

## Your layout is saved

Dock customization is saved to your device's `localStorage`. Your layout persists across app restarts. If you use **Reset App** in Settings, the dock layout resets to default along with all other app data.
